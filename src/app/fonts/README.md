Newsreader-Medium.ttf (a static wght 500 / opsz 72 instance of the OFL 1.1 variable font, made with fonttools) is vendored here only for the images that Next.js
generates at build time: the favicon, the Apple touch icon, and the Open Graph
card. The pages themselves load Newsreader through `next/font` in `layout.tsx`.
See OFL.txt for the license.
